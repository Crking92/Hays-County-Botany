# Hays Botany ID — Project Rules

## Target zone
Hays, Bell, Blanco, Burnet, Comal, Concho, Crockett, Edwards, Frio, Gillespie, Bandera, Kimble, Kinney, Maverick, McCulloch, Medina, Menard, Real, San Saba, Tom Green, Travis, Uvalde, Val Verde, Williamson, Kerr.

## Native threshold
A plant counts as native to the project target zone when it is documented as native in **at least 3 target-zone counties**.

## Range authority priority
1. BONAP / NAPA
2. USDA PLANTS
3. Lady Bird Johnson Wildflower Center / NPSOT
4. iNaturalist / Leafminers / herbaria as supporting evidence

Never invent county occurrence. Mark unresolved when evidence is insufficient.

## Identification method
Strict morphology first: floral and reproductive structures, phyllotaxy, leaf morphology, sap, stem features, fruit/seed structures, measurements, and diagnostic look-alikes. Do not identify primarily by flower color.

## Species folder standard
`species.json + SOURCES.txt + image-sources.csv + images/`

## Image roles
Habit; leaves/phyllotaxy; stem/attachment; flower front; flower side/close-up; reproductive structures; fruit/seed; look-alike comparison.

## Photo use
Keep source, creator, license, URL and diagnostic role with selected images. Private study suitability and public reuse permission are separate statuses.
