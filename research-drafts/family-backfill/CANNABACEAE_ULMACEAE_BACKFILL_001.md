# Cannabaceae vs Ulmaceae Backfill 001

## The fastest field split

These two are easy to confuse because both can have **alternate, serrated, asymmetric leaves**.

Do **not** stop at the asymmetric leaf base.

### Hackberry / Celtis — Cannabaceae
**Look first:** trace the veins from the leaf base.

- usually **3 strong primary veins from/near the base**
- often asymmetric leaf base
- fruit = **fleshy drupe**

### Elm / Ulmus — Ulmaceae
**Look first:** trace the side veins from the midrib.

- **pinnate venation**
- many lateral veins run toward/into the marginal teeth
- fruit = **dry winged samara**

## If fruit is present

This becomes almost trivial:

**Celtis = berry-like drupe**  
**Ulmus = papery winged samara**

## Priority cards

### Celtis laevigata
Start with the three basal veins; confirm with the small fleshy drupe.

### Celtis reticulata
Same family architecture, but with conspicuously netted venation.

**Taxonomy cleanup:** current POWO treats *Celtis laevigata var. reticulata* as a synonym of accepted *Celtis reticulata*. Do not build two learner species from those two Master Pool rows.

### Ulmus crassifolia
Start with pinnate side-veins and an oblique serrated leaf. Confirm with the winged samara. Corky twig wings are a useful secondary clue.

## Learner rule

> **3 veins from base + drupe = think Celtis.**  
> **Many side veins + samara = think Ulmus.**
