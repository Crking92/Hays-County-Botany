# Research drafts

This folder is populated by the unattended Botany Scout.

Everything here is **candidate material for curation**, not canonical botany data.

The scout may collect taxonomy candidates, supporting county-occurrence leads, exact iNaturalist observation/photo IDs, creator and license metadata, direct image URLs, diagnostic-image needs, and a photo contact sheet.

The scout must never assign final project range status, treat occurrence counts as proof of nativity, write directly to `content/taxa/` or `curation-inbox/`, replace curated exact photographs, or silently promote a research draft into the learner.

Normal flow:

`research-queue.json → research-drafts/ → human/ChatGPT curation → curation-inbox/ → existing GitHub curation pipeline`
