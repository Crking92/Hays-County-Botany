1. Read the routing index and original record before starting new collection.
2. Refresh the current destination and work claims.
3. Locate/download the actual file and verify identity and visible diagnostic structures.
4. Preserve source credits and study/public-use metadata.
5. Install public-cleared material normally; install study-only material only into confirmed local/private/authenticated delivery.
6. Record missing binary, uncertain identity, or missing diagnostic roles explicitly.
