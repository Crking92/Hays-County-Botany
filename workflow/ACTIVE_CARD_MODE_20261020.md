## Minimal per-species workflow
1. Read **only the target species.json** and **relevant genus.json / immediate look-alikes**. Check whether the species is canonical from its path or a narrow manifest lookup. Inspect active work claim for THAT taxon/scope (and branch SHA just before writing); do not dump full manifest, historical queue, source pool, reports, or every policy document into conversation. If truly uninstalled, use FIRST CARD lane.
2. Make a tiny internal gap list: recognition clue, look-alike separation, useful licensed real photos, existing arrow accuracy, missing diagnostic structures. Reuse verified photo records/library first; search only for an ACTUAL gap. Never recrawl sources that already fill that role without reason.
3. Modify the existing species card and only the **relevant** genus/family comparisons. Preserve canonical identity, original source/licensing metadata, historical science and unreviewed nativity. Do not overwrite unrelated work; refetch target file SHA before changing it.
4. Label outputs honestly: **PROVISIONAL** = admitted with at least one real licensed photo; **FIELD-READY, PHOTO GAPS** = practical recognition lesson but decisive macro still missing; **FINISHED** = critical diagnostic evidence/annotations actually verified. Never set FINISHED because of photo count.
5. Commit a substantial validated change. For a visible site update, make a single controlled `workflow/field-id-publication/*.json` marker and check the Pages outcome; group related edits when practical. No empty commits or redundant deployments. Short user report: **changed / published? / remaining true gap**.
