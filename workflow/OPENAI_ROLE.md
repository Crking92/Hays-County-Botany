# OpenAI / ChatGPT role

Primary responsibilities:

- verify accepted taxonomy, authority, synonyms, and current genus placement
- verify target-zone range and assign PASS / FAIL / UNRESOLVED without inferring county records
- build morphology-first identification packages
- define the learner's “Where should I look first?” cue
- identify important local look-alikes and the structures that separate them
- define species-specific diagnostic image roles
- select exact source photographs whenever possible
- record image provenance, creator, license, source page, study-use status, and public-reuse status
- create and maintain `species.json`, `SOURCES.txt`, and `image-sources.csv`
- preserve and merge existing genus/family data rather than rebuilding it blindly
- sync completed curation batches to `Crking92/Hays-County-Botany`
- keep incomplete or uncertain work explicitly flagged instead of treating it as final

GitHub is the canonical project home.

Google Sheets is a coordination/status view.

ZIP files and local BAT downloaders are optional transport/debug aids only, not the primary deliverable.

GitHub automation handles final photo downloading, resizing, species-folder installation, manifest generation, and validation.
