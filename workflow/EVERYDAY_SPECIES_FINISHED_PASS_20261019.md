# Everyday Plants — manual finished field-ID pass (2026-10-19)

**Purpose:** Polish species repeatedly encountered by landscape and conservation crews in Kyle, Buda, San Marcos and Hays County into genuinely usable, public-web-cleared visual ID lessons. The user selects species based on daily encounters; iNaturalist observation counts are a biased lead, not an abundance census. Native and non-native weeds/turf are equally eligible as encountered plants.

## Scope / worker coordination

This is a user-led **manual one-species-at-a-time finish pass**, not an additional scheduled worker or an alternative first-card installation lane. Check live `data/manifest.json`, `workflow/work-claims.json`, active GitHub Actions, `workflow/COORDINATION.md`, `workflow/photo-library/README.md`, family/genus lessons, and `workflow/PUBLIC_PHOTO_REUSE_POLICY_20261019.md` before each target. Claim only the narrowly scoped species finish work and do not collide with active Diagnostic Photo Fast-Fill, Genus, Family, Taxonomy or Installer. Preserve all existing good science, original photos and credits; any genus/family module owned by an active worker gets a specific handoff rather than a competing overwrite.

## A completed, credible species pass includes

1. **Identity:** accepted species/rank, synonyms, family, genus and sources; resolve taxonomic ambiguity instead of pretending certainty.
2. **Field recognition:** whole plant, habitat and growth habit, vegetative leaf/stem/branching/roots, seasonal flowering and fruit recognition. Plain language beside botanical terminology. Measurable/observable traits, exceptions, developmental variability, caution against flower-color-only ID.
3. **Anatomical confirmation:** a concise LOOK HERE FIRST sequence and verified tie-breaker structures appropriate to the taxon (phyllaries/cypselae for composites; cyathia/indumentum/styles for euphorbs; ligule/spikelets/awns for grasses; corona/hoods for milkweeds; flower/leaf/fruit structures as applicable).
4. **Locally realistic look-alikes:** usually two to five Hays/nearby species, including common planted/introduced comparisons. Comparison matrix or simple decision key points to *the exact structure that differs*, when the trait overlaps, and what not to trust. Ensure both names actually correspond to accepted taxon concepts.
5. **Ecology and management:** credible local habitat/seasonality/encounter context and practical crew recognition notes. Add caterpillar/bee host specifics only with appropriate species-level evidence; don't create unsupported counts. Project-wide exhaustive native-by-county auditing stays deferred; introduced/invasive labels need separate evidence.
6. **Photo-led teaching:** photos fulfilling Recognize It (whole plant), Look Closer (leaf, attachment, reproductive parts) and Confirm the ID (actual close-up tie-breaker), optionally season-specific fruit/dormancy, ideally two to six useful *different* views, not a numeric quota. Real image pixels must be inspected at appropriate scale before labeling structures or attaching arrows, and coordinates verified. Missing views explicitly listed as pending, never invented.
7. **Public rights:** only newly install individual images whose public website display is permitted: verified photo-level CC0/PD, CC BY/SA, site-authorized personally owned Glass Root Garden, or appropriately reviewed CC BY-NC for the actual strictly noncommercial educational site. Respect photographer, exact image/observation ID, source URL, license/version, modification/change notices, ShareAlike and metadata. Don't assume an iNaturalist photo is reusable simply because it is visible online. PRIVATE-STUDY-ONLY and unknown third-party photos are disallowed as new canonical sources, especially because the GitHub repository itself is now PUBLIC.
8. **Real completion:** verify canonical GitHub species JSON, source log, physically present credited image files and family/genus routes after narrow commit; provide exact SHA/paths. If any essential ID or image-role/rights verification is still unresolved, write **PASS_IN_PROGRESS**, not finished; record precisely what is missing. Use `FINISHED_FIELD_ID_PASS` only after legitimate visual, scientific, rights and readback QA. Live GitHub Pages updates only after manually running the site's publishing workflow with Publish checked; current GitHub source is public immediately on commit.

- **Calyptocarpus vialis / straggler daisy:** 3 photographs; existing botanical detail and exact photo anatomy not fully reviewed. High value to improve tiny flower head, leaf and three-angled fruit, and distinguish creeping look-alike groundcovers. No genus lesson found at inspection.
- **Phyla nodiflora / turkey-tangle frogfruit:** 3 photographs and substantial reviewed field morphology. More efficient near-complete pilot: close-up leaf teeth and flower head, strengthen comparisons to Phyla lanceolata, Phyla cuneifolia, Glandularia spp., inspect part labels and image rights.
- **Croton monanthogynus / prairie tea:** 3 photos and good morphology/croton comparison foundation; needs genuinely diagnostic macro showing hairs on leaf underside and pistillate reproductive structure, not more habit images.
- **Cynodon dactylon / Bermudagrass:** key turf recognition; runners, ligules, raceme/spikelets, comparison to everyday grasses.
- **Sorghum halepense / Johnsongrass:** common disturbed-ground grass; rhizome, ligule, inflorescence and spikelet detail against similar grasses.

These are **suggestions, not claims or promised finished work**. The user chooses the first target and may replace any with plants they encounter more often. Complete one selected species at a time, then add the next.
