## Rules for this working copy

1. Keep the GitHub repository private.
2. Do not move the optional Pages workflow into `.github/workflows/` while any row in `IMAGE-SOURCES.csv` is pending.
3. Do not treat “educational,” “nonprofit,” “linked,” or “credited” as automatic permission.
4. For every photograph, record the exact photographer or rights holder, the license or written permission, the source page, and any required credit language.
5. Replace a pending photograph with Calvin’s own photograph or a clearly compatible licensed image whenever possible.
6. If UT grants permission, save the written terms with the project and follow any limits on audience, alteration, download, or attribution.

## Public-release checklist

- [ ] Every local photograph has written permission or a compatible license.

- [ ] Required creator names and license links appear beside the photograph.
- [ ] The two workbooks have been checked for personal or restricted information.

- [ ] `IMAGE-SOURCES.csv` contains no `permission pending` or `rights require review` rows.
