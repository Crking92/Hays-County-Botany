# UT archive research materials

These files support a future, permission-aware review of the UT BIO 406D PlantPics archive.

- `ut_archive_inventory.json` records 381 linked plant pages, 380 successfully reviewed pages, 1,895 indexed image references, 69 detected family labels, and one fetch error from the audit run.
- `ut_archive_audit.py` recreates the inventory from the public archive index.

The inventory contains page text, captions, and image URLs. It does not establish copyright ownership, a license, botanical suitability, or permission to download and republish a photograph. Treat every item as a research candidate until its rights and visible diagnostic value are checked by a person.

The current guide uses only 12 selected UT photographs, all marked private-study and permission-pending.
