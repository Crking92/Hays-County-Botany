## Practical collection protocol

1. Confirm taxon using several diagnostic features and source specimen/voucher; photograph whole plant first.
2. For ligule: pull sheath away at true **inside** blade/sheath joint, place 1-mm rule, shoot perpendicular close-up in even shade, record original file and specimen.
3. For roots/rhizome: isolate one clump, expose and clean entire crown, retain attached shoots and all connecting rhizome/root nodes in the same frame; avoid planting/moving potentially invasive fragments.
4. For florets: photograph one whole attached inflorescence, then separate and arrange glumes, lemma, palea and bristles on millimeter graph paper. Distinguish vegetative hairs from florets.
5. Preserve original, attribution, explicit source photo license, host observation metadata and image SHA256. Install JPEGs locally in GitHub, add arrows **only to visible structures** and verify Pages after deployment.
6. Scores remain unchanged pending source-licensed actual verified photos. This audit file is a field-capture and source-screening handoff, not photographic completion.
