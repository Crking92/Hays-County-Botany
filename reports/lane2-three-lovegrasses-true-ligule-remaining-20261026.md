## Exact photo protocol for crew / botanical contributors

1. Verify the species on a flowering plant using the existing authenticated photo card, full panicle and spikelets; photograph the exact plant rooted in context. Photograph a labeled plant/voucher as needed rather than relying on the photo of a different *Eragrostis* species.
2. Pick a mature, **attached green leaf** below the flowering culm. Take a crisp **outside** sheath/collar image that includes whole sheath summit, long oral hairs, the blade base and nearby stem; show which hairs arise from which tissue.
3. Gently peel the same blade backward from its sheath. Photograph **from the inside** (adaxial side) exactly where blade joins sheath, with the tiny ligule in focus. Take a side-on view. Put a real 0.5- or 1-mm reference **in the same focus plane**. At 10–30× capture both inner base and actual margin/fringe. Fingers alone are **not** a calibrated scale.
4. Photograph a second crop with **long external collar/oral hairs AND short true ligule separated**. Keep the source scale and do not confuse old split sheath fibers, pulled-away tissue, torn blades, leaf hairs or pressed-herbarium artifacts with the true ligule.
5. Photograph the same rooted crown and its connected shoots; for purple lovegrass also expose short rhizomes. Preserve original photographer, taxon, locality/observation ID, original per-photo reuse license/permissions, and all adaptations. Strip GPS/EXIF from public JPEG copies.
6. When a candidate is verified, physically archive a new exact-species JPG, write image-specific creator/license/source and actual pixel evidence, place arrow endpoints only on documented pixels, read back the commit, publish through **existing rights-filtered GitHub Pages workflow**, and review live rendered arrows before strict completion.
